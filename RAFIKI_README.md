# Rafiki App

**Rafiki** means "friend" in Swahili.

## Original Purpose
A person feels alone. They don’t have a partner or friends to talk to, share feelings, or exchange ideas.

After login the user should:
1. See people who also want real conversation
2. Start a chat easily
3. If no one is available → be directed to TikTok or Facebook

## Project Structure
- `rafiki-web/`     → React + Django
- `rafiki-mobile/`  → Flutter + Django

Both share the same core purpose and Instagram-style direction.
